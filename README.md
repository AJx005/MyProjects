## Featured Project

### RetailX Customer Segmentation & Predictive Analytics
A business analytics project using **K-Means clustering** to identify customer segments and a **Decision Tree classifier** to predict segment membership, followed by business-focused profiling and targeted marketing recommendations.

**Highlights**
- 3 customer segments identified with K-Means
- 14 demographic and behavioural modeling features
- 87.25% Decision Tree test accuracy in the submitted notebook
- Business recommendations tailored to each customer segment
- Tools: Python, pandas, scikit-learn, matplotlib, seaborn, Google Colab
